# Choix éditoriaux soumis à réexamen

Les choix ci-dessous sont appliqués de manière réversible, sauf C21 qui prépare un chapitre ultérieur. Aucun avis humain indépendant n’a été reçu ; cela ne constitue pas une condition de publication.

## C01 — élément, avec membre comme synonyme à la définition

Autre solution considérée : membre partout.

Motif : Élément est directement utilisé dans l’axiome de la référence ; membre reste présent pour conserver les deux désignations de la source.

Confiance : high — Même objet mathématique et usage visible dans le canon.

Question de réexamen : Le maintien du synonyme membre dans la définition suffit-il aux renvois ultérieurs ?

Segments : OLP-0005-B04, OLP-0005-B05, OLP-0005-B06 ; passages : L01.

## C02 — si et seulement si

Autre solution considérée : ssi.

Motif : La forme développée rend les deux directions visibles dans les définitions et les preuves, sans exiger la maîtrise préalable de l’abréviation.

Confiance : high — Le canon emploie ssi ; le développement garde exactement la biconditionnelle.

Question de réexamen : Conserver la forme développée dans les longues preuves ultérieures ou abréger après introduction ?

Segments : OLP-0005-B06, OLP-0006-B09, OLP-0009-B05, OLP-0010-B09 ; passages : H03.

## C03 — article défini expliqué, unicité conditionnée à l’existence

Autre solution considérée : traduire littéralement the par le et affirmer existence et unicité.

Motif : Le français emploie l’ devant ensemble ; expliquer l’article défini restitue l’accent pédagogique. Le principe ne prouve que l’unicité conditionnelle, comme le précise ensuite Russell dans OLP.

Confiance : high — Confirmation explicite dans l’axiome et sa remarque, ainsi que dans OLP-0010.

Question de réexamen : La note éditoriale distingue-t-elle assez clairement la correction de la traduction ?

Segments : OLP-0005-B07, OLP-0010-B04 ; passages : L07.

## C04 — frères et sœurs ; un frère ou une sœur

Autre solution considérée : fratrie ; membre de la fratrie.

Motif : Le premier groupe décrit la collection ; la seconde expression teste l’appartenance d’une personne. Fratrie serait plus compact mais moins transparent pour ce premier exemple.

Confiance : medium-high — Le lien familial est celui du texte anglais ; le canon soutient seulement la forme collection/propriété.

Question de réexamen : Frères et sœurs est-il suffisamment naturel pour désigner ici la collection à un seul membre ?

Segments : OLP-0005-B08, OLP-0005-B10 ; passages : L01, L09.

## C05 — entier strictement positif et diviseurs propres positifs

Autre solution considérée : nombre et nombres qui le divisent sans lui être égaux.

Motif : La source omet le domaine positif ; une lecture incluant zéro ou les diviseurs négatifs ne soutiendrait plus l’exemple de 6. Une note signale la clarification, sans changer la formule.

Confiance : high — La somme 1+2+3 démontre le domaine positif attendu ; pas de prétendue définition canonique du nombre parfait.

Question de réexamen : La précision serait-elle mieux intégrée dans une convention générale sur les diviseurs ?

Segments : OLP-0005-B11 ; passages : L04, L07.

## C06 — sous-ensemble, synonyme partie ; ensemble des parties

Autre solution considérée : partie partout ; ensemble puissance.

Motif : Les deux noms du sous-ensemble sont attestés conjointement par Habermehl. Sous-ensemble rend visible l’inclusion au début ; ensemble des parties est la désignation du power set utilisée à Lyon.

Confiance : high — Les définitions canoniques portent exactement sur les mêmes relations et construction.

Question de réexamen : À quel moment passer à partie dans les chapitres plus avancés sans créer une rupture terminologique ?

Segments : OLP-0006-B03, OLP-0006-B05, OLP-0006-B14 ; passages : H01, L05.

## C07 — sous-ensemble strict

Autre solution considérée : sous-ensemble propre.

Motif : Strict exprime immédiatement inclusion et inégalité ; propre est possible mais rencontre plus tard classe propre avec un autre contraste.

Confiance : medium-high — Choix éditorial motivé par la formule OLP ; H01 atteste seulement sous-ensemble, pas strict.

Question de réexamen : Le terme strict convient-il aussi aux emplois adjectivaux ultérieurs ?

Segments : OLP-0006-B05 ; passages : H01.

## C08 — rendre e distinct de a, b, c explicite

Autre solution considérée : laisser la distinction des lettres tacite.

Motif : L’exemple négatif devient faux si e=a. L’hypothèse minimale ajoutée protège le sens sans supposer inutilement que a, b, c sont eux-mêmes distincts.

Confiance : high — Contre-exemple immédiat e=a.

Question de réexamen : Adopter une convention locale de lettres distinctes pour les autres exemples analogues ?

Segments : OLP-0006-B06 ; passages : H01.

## C09 — abrège ; implication sous le quantificateur universel, conjonction sous l’existentiel

Autre solution considérée : exprime ; reformuler les deux restrictions de manière identique.

Motif : La différence entre implication et conjonction constitue précisément le contenu de la définition ; les formules sont conservées sans modification.

Confiance : high — Les deux formules OLP et leurs portées sont contrôlées directement.

Question de réexamen : Faut-il une future note sur le cas vide lorsque ces abréviations seront utilisées dans des preuves ?

Segments : OLP-0006-B11, OLP-0006-B12 ; passages : L07, L09.

## C10 — entiers naturels à partir de zéro ; entiers relatifs ; entiers strictement positifs

Autre solution considérée : nombres naturels ; entiers ; entiers positifs.

Motif : La source inclut zéro dans Nat et l’exclut de PosInt. Strictement positifs évite l’ambiguïté française de positif ; relatifs distingue Int de Nat.

Confiance : high — La construction des entiers naturels et relatifs est visible dans L04 ; PosInt est lu directement dans OLP.

Question de réexamen : Garder relatifs à chaque occurrence ou autoriser entiers quand le domaine est clair ?

Segments : OLP-0007-B04, OLP-0007-B05, OLP-0007-B06 ; passages : L04.

## C11 — mot fini ; mot vide ; longueur

Autre solution considérée : chaîne finie de symboles ; chaîne vide.

Motif : Le cours d’informatique construit les mots à partir du mot vide et des lettres. Ce choix relie les strings de la première section aux words de la seconde, qui ont ici le même sens.

Confiance : high — Définition inductive et emploi sur un alphabet effectivement consultés.

Question de réexamen : Les futurs usages informatiques de string nécessiteront-ils chaîne lorsqu’il s’agit de données textuelles plutôt que de langages formels ?

Segments : OLP-0007-B07, OLP-0009-B18 ; passages : H02.

## C12 — suite infinie qui se prolonge dans une seule direction

Autre solution considérée : suite bi-infinie ou liste infinie sans qualification.

Motif : La précision une seule direction conserve le domaine indexé à partir de 1 et exclut une indexation par tous les entiers relatifs.

Confiance : high — La qualification est explicite dans OLP ; le canon n’est consulté que pour le registre des suites.

Question de réexamen : La distinction avec suite bi-infinie devra-t-elle être rappelée dans les chapitres de calculabilité ?

Segments : OLP-0007-B08 ; passages : L11.

## C13 — réunion ; de A, de B, ou des deux

Autre solution considérée : union ; soit A soit B.

Motif : Réunion est le choix de Lyon ; Habermehl emploie union. La mention ou des deux interdit la lecture exclusive du ou et conserve la disjonction de la formule.

Confiance : high — Deux usages concurrents réellement observés, et portée disjonctive vérifiée.

Question de réexamen : Faut-il ajouter union comme synonyme lors de la première définition pour le lectorat informatique ?

Segments : OLP-0008-B03, OLP-0008-B07, OLP-0008-B20 ; passages : L08, H01.

## C14 — à la fois ; qui ne sont pas

Autre solution considérée : et ; sauf ceux de B.

Motif : À la fois souligne la conjonction de l’intersection. La relative négative porte sur l’appartenance à B dans la différence, sans exclure tout B de l’univers.

Confiance : high — Les prédicats et leur négation correspondent à la diapositive 8.

Question de réexamen : Le syntagme différence ensembliste apporte-t-il encore une information utile après la définition ?

Segments : OLP-0008-B12, OLP-0008-B13, OLP-0008-B27 ; passages : H01.

## C15 — famille non vide pour l’intersection sans univers fixé ; exception explicitée

Autre solution considérée : accepter une intersection vide comme ensemble de tous les objets.

Motif : La condition universelle sur la famille vide est vraie de tout objet. Sans univers fixé elle ne définit pas un ensemble ; dans U, l’intersection vide peut être U. La restriction est signalée comme éditoriale.

Confiance : high — Conséquence directe de la quantification vide ; H01 fournit explicitement le cadre ambiant alternatif.

Question de réexamen : La note suffit-elle à préparer les futures intersections de familles éventuellement vides ?

Segments : OLP-0008-B19, OLP-0008-B21, OLP-0008-B24 ; passages : L07, L09, H01.

## C16 — couple, avec paire ordonnée comme synonyme

Autre solution considérée : paire ordonnée partout.

Motif : Paire ordonnée est le terme exact de Lyon ; couple est plus léger dans les preuves françaises. Le synonyme conserve le lien vers la source canonique.

Confiance : medium-high — Le sens est fixé par l’égalité coordonnée par coordonnée ; le choix couple n’est pas attribué au passage consulté.

Question de réexamen : Préférer paire ordonnée dans le titre pour renforcer la continuité avec le canon ?

Segments : OLP-0009-B03, OLP-0009-B04, OLP-0009-B06 ; passages : L02.

## C17 — composante ; n-uplet ordonné ; emboîtement à gauche

Autre solution considérée : élément ; n-tuple ; emboîtement à droite.

Motif : Composante distingue les coordonnées des membres de l’ensemble qui code le couple. L’emboîtement à gauche est celui d’OLP et ne doit pas être remplacé par une autre convention.

Confiance : high — Définition anglaise et toutes les expressions emboîtées contrôlées ; n-uplet est un jugement éditorial.

Question de réexamen : La distinction composante/membre devra-t-elle être rappelée au traitement formel des fonctions ?

Segments : OLP-0009-B05, OLP-0009-B08 ; passages : L02.

## C18 — définition par récurrence ; montrer par récurrence

Autre solution considérée : définition récursive ; montrer par induction.

Motif : Dans ces occurrences, l’indice est un entier naturel k. Récurrence est l’usage visible dans Lyon ; les chapitres sur induction bien fondée pourront demander une autre distinction.

Confiance : medium-high — Application limitée ici à k naturel ; aucune généralisation à toute induction.

Question de réexamen : Maintenir définition récursive ailleurs pour distinguer construction et démonstration ?

Segments : OLP-0009-B12, OLP-0009-B17 ; passages : L11.

## C19 — ne pas s’appartenir à soi-même ; supposition et contradiction dans les deux cas

Autre solution considérée : non-auto-membre ; raccourcir à R appartient ssi R n’appartient pas.

Motif : Le groupe verbal évite un adjectif artificiel. Le développement conserve séparément les hypothèses R dans R et R hors de R pour les lecteurs débutants.

Confiance : high — Les deux sens ont été comparés à la preuve source et au paradoxe dans le canon.

Question de réexamen : La répétition finale de être/ne pas être est-elle la plus lisible sans perdre les deux polarités ?

Segments : OLP-0010-B07, OLP-0010-B10, OLP-0010-B11 ; passages : L06.

## C20 — affirmation contradictoire ; théorie naïve

Autre solution considérée : affirmation inconsistante ; théorie vraiment naïve.

Motif : Ici inconsistent qualifie l’affirmation d’existence menant à une contradiction, pas encore une propriété formelle d’un calcul. Contradictoire suit l’explication canonique et évite de trancher prématurément tout le lexique de consistency.

Confiance : high — Usage du canon et rôle local du mot concordent ; décision explicitement locale.

Question de réexamen : Quel terme général retenir après consultation des chapitres consacrés aux théories cohérentes ?

Segments : OLP-0010-B12, OLP-0010-B13 ; passages : L06, L09.

## C21 — préférence provisoire : au plus dénombrable pour la propriété incluant fini et vide

Autre solution considérée : dénombrable avec convention inclusive annoncée.

Motif : Lyon atteste les deux conventions dans la même définition. La forme explicite évite de demander au lectorat francophone de deviner laquelle s’applique. Elle ne sera appliquée qu’après lecture des définitions OLP du chapitre concerné.

Confiance : medium-high — Convention inclusive attestée ; adjudication finale OLP encore à faire.

Question de réexamen : Les macroformes adjectivales exigent-elles un usage abrégé de dénombrable après convention explicite ?

Segments :  ; passages : L10.

## C22 — hypothèses locales c≠d et b≠d, signalées en notes

Autre solution considérée : supposer toutes les lettres distinctes dans tout le chapitre.

Motif : Les deux hypothèses suffisent aux intersections annoncées. Elles répondent exactement aux contre-exemples relevés par le manager, sans ajouter de restriction globale aux autres énoncés.

Confiance : high — Vérification directe des appartenances et contre-exemples c=d ou b=d hors des éléments affichés.

Question de réexamen : Ces précisions locales sont-elles plus lisibles qu’une convention limitée aux exemples ?

Segments : OLP-0008-B15, OLP-0008-B22 ; passages : H01.

## C23 — a, b et c distincts de 0 et de 1 dans cet exemple

Autre solution considérée : traiter tacitement les lettres comme différentes des chiffres.

Motif : L’intersection affichée n’est vide que si les deux ensembles sont disjoints ; la formulation explicite uniquement la condition déjà annoncée dans le texte.

Confiance : high — Prendre a=0 donne immédiatement un contre-exemple à l’égalité sans hypothèse.

Question de réexamen : Une convention d’exemples pourrait-elle alléger ces notes dans une révision future ?

Segments : OLP-0008-B14 ; passages : H01.

## C24 — distinguer les mots abstraits de leurs représentations non munies de longueur

Autre solution considérée : identifier sans restriction les symboles et les couples de tout alphabet.

Motif : Si l’alphabet contient le symbole ensemble vide, le codage original confond déjà le mot vide et un mot de longueur un. Le code de chaque longueur positive reste injectif ; associer la longueur à la représentation distingue les mots. La formule originale est préservée et son statut de représentation est explicité.

Confiance : high — Contre-exemple direct A contenant l’ensemble vide ; différence entre mot inductif dans H02 et couple codé dans L02.

Question de réexamen : Faut-il adopter une définition par fonctions à domaine initial fini dans le futur chapitre formel sur les suites ?

Segments : OLP-0009-B18 ; passages : H02, L02.

## C25 — articles français devant les renvois ; renvoi conditionnel entre parenthèses

Autre solution considérée : calquer in/using par dans/à l’aide de sans article.

Motif : Le PDF révélait Dans Section et À l’aide de Définition. Ajouter la et régler les noms automatiques en minuscules produit dans la section et à l’aide de la définition. Le renvoi futur à une étiquette de type encore variable est parenthétique.

Confiance : high — Constat du lecteur compilé et accord syntaxique français ; la référence garde exactement son identifiant.

Question de réexamen : Les futurs renvois multiples exigent-ils une macro qui choisisse aussi le pluriel et l’article ?

Segments : OLP-0007-B05, OLP-0008-B04, OLP-0008-B12, OLP-0009-B07 ; passages : L06.

## C26 — police Unicode ; guillemets français ; groupe vide après le point d’exclamation actif

Autre solution considérée : accents et ligatures saisis par commandes TeX ; guillemets droits.

Motif : Le passage au moteur XeTeX avait exposé un défaut de police huit bits : sœur perdait sa ligature et les guillemets étaient mal affichés. Une police Unicode conserve l’orthographe écrite. Le groupe vide empêche le mécanisme OLP des points d’exclamation de supprimer l’espace suivant.

Confiance : high — Défauts constatés dans le PDF et le journal de compilation ; orthographe et espacement inspectés à nouveau après réparation.

Question de réexamen : Vérifier les autres langues et macros de ponctuation lors des chapitres suivants, sans extrapoler cette correction à des opérateurs mathématiques.

Segments : OLP-0005-B04, OLP-0005-B08, OLP-0005-B10, OLP-0010-B05, OLP-0010-B11 ; passages : L06.

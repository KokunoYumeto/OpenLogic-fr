## Construction mathématique et différences de notation

Dans le zigzag, la case(n,m) a le numéro T(n+m)+n, avec T(s)=s(s+1)/2. Sur une diagonale de somme s, n parcourt0à s ; les numéros parcourent donc le bloc de T(s) à T(s)+s=T(s+1)−1. Ces blocs consécutifs partitionnent les naturels. Cela justifie la fonction inverse employée dans la preuve et le fait que chaque couple est atteint après un nombre fini d’étapes. Les trois tableaux, la liste des dix premiers couples, les ensembles affichés et les formules sont conservés. Le codage des triplets est bien celui de couples emboîtés déjà adopté par OLP. La convention Nat^0 singleton du0-uplet est rendue explicite et signalée ; elle complète la définition antérieure commençant à1 pour couvrir le quantificateur n∈Nat.

Dans pairing, la formule T(n+m)+n est gardée. Le témoin français K01 emploie T(x+y)+y : il atteste le nom fonction de couplage, mais sa convention de coordonnées ne remplace pas celle d’OLP. La somme0+…+k vaut k(k+1)/2 ; la somme des naturels strictement inférieurs à k ne le vaut pas. La borne est corrigée et expliquée. Passer de m à m−1 exige m≥1, condition également signalée. Un couplage est une injection ; son inverse n’a pour domaine que son image. Pour un contre-exemple à l’exercice original, prendre f(n,m)=2(T(n+m)+n) : les codes impairs n’ont pas d’antécédent. Si le produit est non vide, on peut composer l’inverse sur l’image avec une énumération de cette image, ou traiter les codes inutilisés au moyen d’une valeur de remplacement fixe ; si le produit est vide, on emploie la liste vide. La consigne corrigée demande de construire l’énumération à partir de l’inverse, sans donner cette solution dans le lecteur. La note sur la réunion dénombrable identifie un principe de choix suffisant lorsque les énumérations ne sont pas fournies ; elle n’affirme pas sa nécessité pour chaque famille particulière.

## Paraphrases inverses de contrôle

- Zigzag : every pair occurs in exactly one cell; numbering diagonals by increasing coordinate sum produces consecutive finite blocks and reaches every pair. The product of zero factors has one empty tuple. This is a countability construction, not the non-countability diagonal argument.
- Pairing : an arithmetic pairing function injects A×B into Nat; a code recovers at most one pair, and decoding is total only on the used codes. The union exercise presupposes or chooses the separate enumerations before listing their values together.
- Alternative pairing : fill alternate remaining empty slots; positions begin at1, so subtract1 to code into Nat. Powers of2 determine the first coordinate. The2^n3^m code need not be onto.
- Non-countability : for each proposed list, construct a binary sequence differing from its kth entry at position k. The witness depends on the list; there is no single sequence claimed absent from every list. For a list of subsets, membership of k distinguishes the diagonal set from the kth subset.
